# MySQL 시절 마이그레이션 (적용된 적 없음)

이 폴더의 8개 마이그레이션은 **어떤 DB 에도 적용된 적이 없습니다.** 개발 기간
내내 `DATABASE_URL` 이 설정되지 않은 상태였고(데이터는 메모리 시드로 돌았다),
DB 를 붙이는 시점에 PostgreSQL(Neon)로 결정되어 새 마이그레이션을 처음부터
생성했습니다 — 사양서 §15 의 권고안입니다.

지우지 않고 남겨 둔 이유는 스키마가 어떤 순서로 자랐는지가 기록이기 때문입니다
(예: `0006` 은 「스키마에만 있고 마이그레이션이 없던 5건」을 뒤늦게 반영한 것).
**실행하지 마십시오.** 현재 스키마의 단일 출처는 `drizzle/erpSchema.ts` 이고,
적용할 마이그레이션은 `drizzle/` 바로 아래 PostgreSQL 파일들입니다.
