### 회의에서 답 주셔야 하는 것 (다음 회차 질문 6건)

1. **VAT 표기 기준** — IP는 (vat별도), 네트워크는 (VAT 포함). 전사 통일 vs 원장 분리 저장 → 세금계산서·부가세 화면, 슬랙 파서 동작
2. **손익 귀속 기준일** — 착수일 / 최종 업로드일 / 지출 요청일 중 어느 것 → 손익계산서의 기간 귀속
3. **성사 가능성 환산율** — 상/중/하를 확률로 (예: 70/40/10) → 13주 자금계획의 파이프라인. 지금은 0으로 두어 낙관 편향을 막고 있습니다
4. **통과원가 계약 구조** — 중개면 예수금(부채), 원가 구조면 영업활동 → 현금흐름표의 3구간 분류
5. **틱톡샵 정산 4가지** — 통화 · 매출 인식 시점 · 플랫폼 수수료 계정 · 총액/순액. **첫 정산 처리가 기준으로 굳습니다**
6. **08-27 미결 4건** — 카드 집행 기록 위치 / 영업·투자·재무 분리 시점 / 채권 자동 메일링 범위 / 사업부 구분 기준
