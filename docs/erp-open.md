## A. 오픈 전 — 환경변수 (Vercel → Settings → Environment Variables → Production)

| Key                      | 값                                  | 없으면                                                    |
| ------------------------ | ----------------------------------- | --------------------------------------------------------- |
| `DATABASE_URL`           | Neon 연결 시 자동                   | **메모리로 뜹니다** — 재시작하면 입력한 내용이 사라집니다 |
| `SESSION_SECRET`         | 직접 생성해 넣기                    | 로그인이 동작하지 않습니다                                |
| `ERP_ROLE_MAP`           | `{"jaybe@dinostudio.kr":"대표", …}` | 아무도 못 들어옵니다 (기본값 닫힘)                        |
| `CRON_SECRET`            | `openssl rand -base64 32` 결과      | 알림 크론이 돌지 않습니다                                 |
| `SLACK_SIGNING_SECRET`   | 슬랙 앱 Basic Information           | 슬랙 수집이 전부 401                                      |
| `SLACK_BOT_TOKEN`        | `xoxb-…`                            | 수집·발송·**첨부 읽기** 불가                              |
| `SLACK_EXPENSE_CHANNELS` | `*`                                 | 아무 채널도 수집 안 함                                    |
| `SLACK_NOTIFY_CHANNEL`   | 알림 받을 채널 ID                   | 알림이 알림함에만 쌓임                                    |
| `ANTHROPIC_API_KEY`      | —                                   | **PDF·이미지 첨부를 못 읽습니다** (이름만 남음)           |

> ⚠️ 비밀값은 **채팅에 붙여넣지 마십시오.** Vercel 에 직접 넣고 「넣었다」만
> 알려주시면 됩니다.

### 슬랙 앱 권한 (OAuth & Permissions → Bot Token Scopes)

`chat:write` · `channels:history` · `channels:read` · **`files:read`** ·
비공개 채널을 쓰면 `groups:history` · `groups:read` 도.

넣은 뒤 **Reinstall to Workspace** → 토큰이 바뀌면 `SLACK_BOT_TOKEN` 갱신.

> `files:read` 가 없으면 슬랙이 파일 대신 **로그인 페이지**를 돌려줍니다.
> 화면에는 「files:read 권한을 추가하십시오」라고 그대로 나옵니다.

> ③ 은 한 번에 안 끝날 수 있습니다. 버튼이 **「이어서 가져오기」**로 바뀌면
> 그대로 다시 누르십시오. 「끝까지 자동으로 가져오기」를 켜면 페이지를 열어 둔 동안 이어서 실행합니다. 페이지를 닫으면 멈춥니다. 여러 번 눌러도 같은 건이 두 번 들어가지 않습니다.

첨부는 「남은 첨부 자동으로 읽기」로 별도 처리합니다. 아직 시도하지 않은 파일부터 읽으며, 실패 파일은 무한 재시도하지 않습니다. 남은 수에는 실패 파일이 포함됩니다.

금액 보완은 승인 완료가 아닙니다. 원문 금액과 확인 근거를 저장한 뒤에도 증빙·계정과목·귀속 검토와 최종 승인이 필요합니다.

## F. 되돌리기 · 사고 대응

| 상황                 | 조치                                                                                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 데이터가 엉켰다      | **시트 이관 → 「코드에 든 사본으로 다시 만든다」** (대표만 · 재인증 · 확인 문구 · 마감 없을 때만). **검수함도 함께 비워지므로 슬랙 수집을 다시 돌려야 합니다** |
| 슬랙이 잘못 수집한다 | `SLACK_IGNORE_CHANNELS` 에 채널 ID (항상 우선)                                                                                                                 |
| 수집을 전부 멈춘다   | `SLACK_EXPENSE_CHANNELS` 를 비운다 (기본값 닫힘)                                                                                                               |
| 알림이 너무 온다     | `SLACK_NOTIFY_CHANNEL` 을 비운다 — 알림함에는 계속 쌓인다                                                                                                      |
| 배포가 깨졌다        | Vercel → Deployments → 직전 배포 **Promote to Production**                                                                                                     |
