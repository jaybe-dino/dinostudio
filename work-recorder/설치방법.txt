업무 녹음 자동화 — 설치

  1. 이 폴더를 압축 해제한 상태로 둡니다.

  2. 터미널을 엽니다.
     (Command + Space → "터미널" 입력 → 엔터)

  3. 터미널에 아래 네 글자를 칩니다. bash 뒤에 반드시 한 칸 띄웁니다.

         bash 

  4. 이 폴더 안의  mac  폴더를 열고, setup.sh 파일을
     터미널 창 안으로 드래그해서 놓습니다.
     (경로가 자동으로 입력됩니다)

  5. 엔터를 누릅니다. 1~2분 뒤 설치가 끝납니다.


설치 후

  ~/Applications 폴더(또는 Launchpad)에서 "업무녹음" 앱을 실행하세요.
  화면 맨 위 상태바에 🎙 아이콘이 생깁니다.

  아이콘을 누르면 나오는 메뉴:

      ● 녹음 시작 / ■ 녹음 종료
      오늘 녹음 정리하기
      녹음 폴더 열기 / 설정 열기 / 점검하기

  로그인할 때 자동으로 뜨도록 등록됩니다.
  (해제: 시스템 설정 → 일반 → 로그인 항목)

  처음 녹음할 때 마이크 권한을 묻습니다. 허용해 주세요.


키 입력 (Google Drive / Notion / Slack)

  메뉴바 아이콘 → "설정 열기" 에서 입력합니다.
  키가 없어도 녹음과 로컬 정리는 동작합니다.


녹음 파일은 어디에?

  ~/업무녹음  폴더 (홈 폴더 안 "업무녹음")
  자동으로 지우지 않습니다.


잘 안 될 때

  · Python 3.11 이상이 필요합니다. 없으면 설치 방법을 안내합니다.
  · 메뉴바 아이콘이 안 보이면: 메뉴 막대가 꽉 찼을 수 있습니다.
    다른 앱 아이콘을 줄이거나, 로그를 확인하세요.
       ~/.work-recorder/menubar.log
  · 그 외 오류는 터미널에 나온 내용을 그대로 알려주세요.
