# 맥에서 쓰기

터미널 없이 **Finder에서 더블클릭**으로 쓸 수 있게 만든 실행 파일들이다.

## 처음 한 번

| 파일 | 하는 일 |
|---|---|
| **설치.command** | 전용 가상환경 생성 → 패키지 설치 → `.env` 준비(API 토큰 자동 생성) → 설정 점검 |

시스템 파이썬을 건드리지 않고 `~/.work-recorder/venv` 안에만 설치하므로 다른 도구와
충돌하지 않는다. Python 3.11 이상이 필요하며, 없으면 설치 방법을 안내한다.

> **처음 더블클릭할 때 "확인되지 않은 개발자" 경고가 뜨면**
> 파일을 **우클릭 → 열기 → 열기**로 한 번만 실행하면 그다음부터는 그냥 열린다.
> (git clone으로 받았다면 격리 표시가 없어 경고가 안 뜬다.)

## 매일 쓰는 것

| 파일 | 하는 일 |
|---|---|
| **테스트 실행.command** | 키 없이 파이프라인 전체 확인. 가짜 녹음 2건으로 수집→전사→분석→출력, 재실행 시 중복 방지까지 보여준다 |
| **설정 열기.command** | `.env`를 텍스트 편집기로 연다 (Google·Notion·Slack·STT 키 입력) |
| **서버 시작.command** | 작업 API + 워커 + 정기 실행(매일 00:05 KST). 창을 닫으면 멈춘다 |
| **지금 정리.command** | 오늘치를 즉시 정리 요청하고 진행 상태를 보여준다. 서버가 떠 있어야 한다 |
| **자동실행 등록.command** | 로그인할 때 서버가 자동으로 뜨도록 LaunchAgent 등록 |
| **자동실행 해제.command** | 위 등록 해제 |

권장 순서: `설치` → `테스트 실행`(동작 확인) → `설정 열기`(키 입력) → `자동실행 등록`.

## 진짜 단일 실행 파일이 필요하면

파이썬이 없는 맥에도 옮겨 쓰고 싶다면, **맥에서** 한 번 빌드한다.

```bash
bash mac/build-binary.sh
```

`dist/work-recorder` 파일 하나가 나온다. 다른 맥으로 옮기면 받는 쪽에서 한 번:

```bash
xattr -d com.apple.quarantine work-recorder
```

Apple 개발자 서명(연 $99)을 하면 이 과정도 필요 없다. 빌드는 반드시 맥에서 해야
한다 — PyInstaller는 크로스 컴파일을 지원하지 않는다.

## 문제가 생기면

| 증상 | 확인 |
|---|---|
| 서버가 안 뜬다 | `tail -f ~/.work-recorder/server.error.log` |
| 지금 정리가 "연결할 수 없습니다" | `서버 시작.command`가 실행 중인지 |
| 마이크 권한 오류 | 시스템 설정 → 개인정보 보호 및 보안 → 마이크 |
| 설정이 잘못됐는지 | `설치.command`를 다시 실행하면 점검 결과가 나온다 (`.env`는 덮어쓰지 않는다) |
