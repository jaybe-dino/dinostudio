# 맥에서 쓰기

## 설치 (한 번만)

터미널에 `bash ` 를 치고 **이 폴더의 `setup.sh` 파일을 터미널 창으로 드래그**한 뒤
엔터. 자세한 안내는 프로젝트 폴더의 `설치방법.txt`.

`setup.sh` 가 하는 일:

1. macOS 격리 속성 제거 — 인터넷에서 받은 파일이 실행되지 않는 원인
2. `~/.work-recorder/venv` 에 설치 (시스템 파이썬은 건드리지 않음)
3. `.env` 생성 + API 토큰 자동 생성
4. **바탕화면에 실행 아이콘 3개 생성** — 이 컴퓨터에서 만든 파일이라
   Gatekeeper가 막지 않는다. 이후로는 더블클릭만 하면 된다
5. 가짜 녹음 1건으로 전체 흐름을 돌려서 눈으로 확인

다시 실행해도 안전하다. `.env` 는 덮어쓰지 않는다.

## 바탕화면 아이콘

| 아이콘 | 하는 일 |
|---|---|
| 업무녹음 설정 | `.env` 를 편집기로 연다 (Google·Notion·Slack 키 입력) |
| 업무녹음 정리 | 오늘 업무일을 지금 정리 (서버 없이 바로 실행) |
| 업무녹음 자동실행 | 매일 00:05 KST 자동 정리 + 작업 API. 창을 닫으면 멈춘다 |

## 왜 .command 파일을 직접 주지 않았나

인터넷에서 받은 `.command` 는 macOS가 격리 속성을 붙여 Gatekeeper가 실행을
차단한다. 반면 `setup.sh` 가 **로컬에서 생성한** 바탕화면 아이콘에는 격리가
붙지 않아 그냥 더블클릭된다. 터미널 한 번으로 그 상태를 만드는 것이다.
